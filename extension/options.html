Send navigation URLs to your local security backend for analysis.

Local-only analysis

Only loopback API addresses are accepted. URL checks and optional AI run on this computer through the backend and local Ollama. The extension stores the token in this browser profile's extension storage. The backend stores redacted extension URLs (credentials, query values, and fragments removed) with scan results.

To get a token, sign in to the dashboard and use Settings → Copy session token. Do not share the token.
